# ECHOES OF THE VOID

Прототип психологического космического хоррора от первого лица на Godot 4.7.

## Документы

- **Сюжет и структура игры: `docs/PLOT.md` — единственный источник истины по истории.** Задание на реализацию для ИИ — §12.
- Арт-дирекшн и атмосфера: `docs/ART_DIRECTION.md`.
- Отчёт о состоянии прототипа: `.codex_qa/work_report/report.md`.
- Схемы механик: `diagrams_echoes_of_the_void.drawio`, `activity_*.xml`, `bpmn_*.xml`.

## Запуск

Открыть `project.godot` в Godot 4.7. Маршрут меню: `scenes/main_menu.tscn` → `scenes/intro_cutscene.tscn` → `scenes/main.tscn`.

## Управление

WASD — движение, мышь — обзор, Space — прыжок, E — взаимодействие, F — фонарь.

## Статус

Готово: интерьер корабля, игрок, радио (фокус камеры, ползунки, диск), фонарь, меню, вступление, пост-обработка, атмосферный звук.

Не реализовано: главы, радиосистема с частотами и пакетами, шлюз, EVA-ремонт, чёрная дыра, сохранения. План — `docs/PLOT.md` §12.
