# ECHOES OF THE VOID — выжимка для нового чата

Дата: 2026-10-22. Проект: `D:\4`, Godot 4.7.2 (`D:\Godot_v4.7.2-stable_win64.exe`),
рендерер GL Compatibility, психологический космический хоррор от первого лица,
стиль PS1/VHS, грязная индустриальная эстетика (Alien / Dead Space / DEEP RADIO).

## Что уже сделано

- **Интерьер корабля** полностью переделан из модульного кита (Blockbench GLB):
  - коридор Deck B: панели, пол-решётка, потолок, лампы, трубы/кабели, верстак с радио;
  - мостик: панорамные окна, консоли с CRT-экранами, капитанское кресло (пропсы);
  - шлюз: круглый люк, скафандр, терминал, ящики;
  - аварийная дверь B-3 с новой металлической текстурой и табличкой B-3;
  - **каюта экипажа** (боковое ответвление от коридора): стены/пол/потолок из кита,
    дверная рама, коллизии, свет; 17 предметов из Blender (двухъярусная койка,
    шкафчик, стеллаж, стол, стул, спальник, кабели, бумаги, личные вещи, труба, вентиляция);
  - ткани на койке: одеяло (`fabric_dirty`), простыня/матрас (`fabric_light`),
    подушка (`fabric_pillow`, отделена в Blender-модели `bunk_bed.glb`).
- **Текстуры** из `D:\4\images` (Gemini): обработаны 512 px, PS1-квантование 5 бит/канал,
  без зеркальной укладки; лежат в `assetss/tex_gemini/{tiles,decals,crt,doors}`.
- **Рантайм-навешивание материалов** (важно): сохранение `PackedScene` теряет
  surface-override у инстансов GLB, поэтому материалы/декали ставятся в рантайме:
  - `scripts/ship_dresser.gd` — стены/пол/потолок/декали/ткани/дверь B-3;
  - `scripts/screen_dresser.gd` — CRT-квады на консолях и терминалах.
- **Космос по сюжету**: 3 стадии (система → пустота → чёрная дыра), `scripts/space_stage.gd`;
  чёрная дыра крупная и читается в окне мостика.
- **VHS-постобработка** `shaders/vhs.gdshader` на `PostFX/Atmosphere` в main/menu/intro;
  меню и вступление в стиле кассеты (Cascadia Mono, REC, «СИГНАЛ ПОТЕРЯН»).
- **Радио**: новая модель из кита, зелёный CRT-экран, фиксированная поза камеры,
  без разворотов на 360° (проверено тестом).
- **Полировка света/декалей/пропсов (пакет C «контрастный хоррор»)** — см.
  `docs/POLISH_2026-10-22.md`: новый свет-риг C (19 ламп, 3 тени, сжатые радиусы),
  VHS «стабильная кассета» B (одинаково в игре/меню/вступлении), ambient 0.20 /
  exposure 0.96; фикс зеркального плаката, 3 новые
  декали (всего 16), фикс белого экрана радио (теперь зелёный CRT), 5 мелких
  пропсов; FPS ~54.6.

## Правила проекта (AGENTS.md)

- Перед изменениями сначала спрашивать вариантами, показывать скриншоты вариантов.
- 1 юнит Blockbench = 1 юнит Godot; bloom в GL Compatibility недоступен (свечение — эмиссия).
- Радио: фиксированная поза через `Radio/CameraTarget`, углы — по кратчайшему пути.

## Технические грабли (наступали)

- Godot не импортирует ассеты из папок с точкой (`.codex_qa`) — только `assetss/...`.
- `build_and_save.gd` собирает сцену своим путём, не через `_run()` из `build_ship.gd`:
  новые шаги добавлять в `_build_save()`.
- `_rebuild_light_rig()` удаляет ВСЕ Light3D и создаёт риг заново — свет новых комнат
  добавлять туда же.
- Декали прижимать к передней плоскости панелей (левый борт z≈10.536, правый ≈13.264,
  стены каюты x≈3.236/6.564, задняя z≈7.236); не ставить декали в зоне проёмов —
  там нет панели, будет «парить».
- Настройки материалов в `ship_dresser.gd`: стены/пол uv1_scale 0.45/0.6, потолок —
  отдельный тёмный материал, дверь 0.55, ткани 0.85; albedo стен ~0.62 (не 0.42 — черно,
  не 1.0 — пересвет).
- Койка: подушка отделена в `bunk_bed.glb` материалом `fabric_pillow`; матрасы — `fabric_light`,
  одеяло+валик — `fabric_dirty` (в маппинге dresser: fabric_pillow → стёжка, fabric_light → простыня,
  fabric_dirty → одеяло). ВАЖНО: скрипты `.codex_qa/rooms/quarters/build_quarters.py`,
  `qbuild_items.py`, `qbuild_lib.py` и общий `quarters_furniture.glb` НЕ обновлены под сплит —
  при пересборке мебели из них вернётся старый расклад материалов. Бэкап старого GLB:
  `.codex_qa/rooms/quarters/bunk_bed_before_pillow.glb`.
- Дверь B-3: `assetss/shipkit/equip/door_b3.glb` (1.43×2.21×0.33 м, origin низ-центр, +Z,
  материалы кит-имена: metal_panel, metal_dark, paint_worn, rust, hazard_y, hazard_k,
  crt_green, red_lamp, glass_grime). Спецификация — `docs/DOOR_SPEC.md`.
- Свет после полировки: `RIG_C` в `build_and_save.gd` — 19 ламп, 3 теневые (#1 коридор,
  #9 мостик, #13 каюта), `omni_attenuation` по умолчанию 1.0 (затухание 1/d, не 1/d²).
  Теней больше не добавлять: FPS 55–59 при 1680×1050, запас небольшой. В GL
  Compatibility действует лимит ~8 ламп на mesh — при добавлении новых комнат следить.
- WorldEnvironment и VHS-пост живут в `scenes/main.tscn` (не в сборщике): ambient 0.20 /
  exposure 0.96 / fog 0.052. VHS-пост — **«стабильная кассета» B** (после правки 22.10,
  пользователь выбрал её вместо жёсткой): `strength` 0.85, `preset` 1, `jitter` 0.12,
  `jump` 0.04, `tracking` 0.15, `tear` 0.08, `scanline` 0.18, `vignette` 0.45,
  `contrast` 1.08, `brightness` 1.12, `saturation` 0.74. Те же значения — в
  `main_menu.tscn` и `intro_cutscene.tscn` (эффект одинаковый везде). Полная таблица —
  `docs/POLISH_2026-10-22.md` §6.
- Сборщик: `_clean_radio_bench()` сравнивает **локальную** `position.x`, а не
  `global_position`: у узла вне дерева `global_position` возвращает origin, и можно
  удалить не тот объект (на верстаке оставался старый CRT-терминал).
- Экран радио: материал `_radio_screen_material()` в `kit_materials.gd` (unshaded CRT);
  `glass_grime` по-прежнему использует `_screen_material()` — не перепутать.

## Что не сделано / идеи

- HUD — по решению пользователя пока без HUD.
- Возможные новые комнаты: техотсек, медотсек, грузовой трюм.
- Новая геометрия двери: пользователь может сделать в другом чате, потом интегрировать.
- Проверить пакет C «в игре руками»: если в тёмных зонах станет некомфортно — вернуть
  мягкие значения из `docs/POLISH_2026-10-22.md` (варианты A2/B) или ослабить VHS.
- В `RIG_C` 19 ламп (лимит ~8 ламп/mesh в GL Compatibility) — при добавлении комнат
  пересчитать свет, иначе часть ламп может перестать влиять на меши.
