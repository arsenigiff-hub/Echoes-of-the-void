# Шаттл «Ариадна» — level design (черновик на утверждение)

Статус: предложение, ничего из этого ещё не построено. Основа — линейный шаттл из
`scenes/shuttle_blockout.tscn` (33 м, 7 отсеков) и сюжет из `docs/PLOT.md`.
Тон: Fears to Fathome / нишевые хорроры с itch.io: обыденные вещи, низкий потолок, лоу-фай,
страх от тишины и следов присутствия. **Без монстров и мистики** (правила `PLOT.md` §3–4).

## 1. Принципы

1. **Один длинный коридор, семь комнат, пять люков.** Игрок всегда видит впереди следующую
   комнату; дальний вид через открытые люки — главный страшный приём.
2. **У каждой комнаты свой цвет света и свой звук** (кабина — холодный голубой, экипаж — белая
   мигающая трубка, камбуз — тёплый янтарь, медотсек — болезненно-зелёный, груз — жёлтая лампа,
   реактор — красный, шлюз — зелёный индикатор). Игрок узнаёт отсек с закрытыми глазами.
3. **Корабль рассчитан на четверых, на борту один.** Три койки/кресла пустые, но обжитые.
   Это тихая тема игры: расстояние и пустота, а не кто-то рядом.
4. **Каждый предмет что-то говорит** (чья кружка, чей кашель, чей рисунок). Предмет без
   функции и без истории не ставим (правило «без нейрослопа»).
5. **Маршрут чтения:** камбуз (пробуждение) → реактор (энергия) → шлюз (панель) → экипаж (радио) →
   кабина (курс) → камбуз (сон). Игрок пройдёт коридор 5–6 раз; к концу он «выучит» корабль,
   и мелкие изменения (свет, предметы, звук) начнут работать как страх.

## 2. Масштаб и единицы

- Ширина 4,8 м, высота 2,5 м, люки 0,95×1,95 м. Игрок — капсула 1,82 м.
- Бюджет моделей: 300–3000 треугольников на предмет, крупная мебель до 5000.
- Стиль моделей: низкополигональный «ретро-промышленный», без неона и голограмм;
  материалы — стёртая краска, ржавчина, вытертый кожзам (текстуры ChatGPT, 5 бит/канал).

## 3. Отсеки

Формат: назначение → сюжетная точка → предметы (**P1** — нужно для игры, **P2** — детали и
следы) → свет → звук → «что здесь настораживает».

### 3.1 Пилотская (нос, 0…4 м)

- **Назначение:** навигация и окно. Сюда игрок возвращается за курсом.
- **Сюжет:** панель навигации (ввод координат Земли, после перехода — расхождение),
  окно (планета, затем Стрелец A*).
- **P1:** навигационная консоль с ЭЛТ-экранами, два пилотских кресла (левое повёрнуто — пилот встал
  и не вернулся), штурвальная рукоять / джойстик, панель автоматов над головой, окно с рамой
  и стойкой.
- **P2:** кружка с остывшим чаем (круглое кольцо на пульте), планшет с чек-листом, шлем
  в сетке на спинке, наклейка «ЭХО 1/4» на пульте, карандаш в зажиме, ремень кресла в узле.
- **Свет:** только свечение панелей (голубой/янтарный), потолочная лампа мертва.
- **Звук:** писк ЭЛТ, треск реле, шипение статики из динамика на низкой громкости.
- **Настораживает:** на левой панели свежая запись курса с отметкой «ПОДТВ.», хотя игрок ничего
  не вводил (это старая авто-команда ЦУП; объясняется позже, до этого — вопрос).

### 3.2 Отсек экипажа (4,3…9 м)

- **Назначение:** радио — единственная связь с домом.
- **Сюжет:** приёмник ловит пакеты Веры (ЦУП) и голосовые письма дочери Миры; журнал записей.
- **P1:** радиоприёмник (полевой, ретро, с ручками и зелёным ЭЛТ), стол радиста с журналом,
  гарнитура, три откидных кресла.
- **P2:** куртка на среднем кресле (не его размер — «на троих»), термос под столом, шкафчик
  с половиной открытой дверцы, бумажный журнал с прожжённым углом, рация-блокнот, коврик из
  кабельных стяжек, фото с таймером «отправка 14:02», календарь с зачёркнутыми днями.
- **Свет:** одна люминесцентная труба, периодически гаснет на 0,3–1 с; при провале слышен гул.
- **Звук:** лампа гудит 100 Гц, ЭЛТ радио потрескивает, дальний скрип корпуса.
- **Настораживает:** на каждом кресле табличка с фамилией; три фамилии аккуратно заклеены полосой
  изоленты. Объяснение в журнале (экипаж сняли с рейса за сутки до старта) — сам игрок не
  узнаёт, почему.

### 3.3 Камбуз и жилая зона (9,3…14 м)

- **Назначение:** стартовая точка, капсула сна (переход через сверхсвет), личное.
- **Сюжет:** пробуждение в темноте; позже сон перед переходом и пробуждение с новым видом.
- **P1:** капсула сна (откидная крышка, ремни, панель с таймером), кухонный блок
  (раковина, плита, шкафчик), шкаф с едой.
- **P2:** детский рисунок и фото над капсулой (Мира), кружки на сушилке (две, а не одна),
  вскрытые пакеты с едой, засохшая каша в миске, ручной фонарь на магните, тюбик с подписью
  «зубная паста» (бытовой текст), календарь, свёрнутый плед, тапочки.
- **Свет:** только тёплая лампа у капсулы (мерцающая янтарная), остальное темно.
- **Звук:** капающий кран, гудение холодильника, «дыхание» вентиляции.
- **Настораживает:** вторая кружка на сушилке ещё мокрая.

### 3.4 Медотсек (14,3…18,3 м)

- **Назначение:** последствия аварии, уязвимость, психологическое.
- **Сюжет:** аптечка нужна после аварии (боль, кровь на рукаве — без кровавых сцен); запись врача.
- **P1:** смотровая кушетка, шкаф с красным крестом, аптечка, стойка капельницы.
- **P2:** бинт, использованный шприц на столе, листок назначений (текст — бытовой),
  хирургическая лампа на штанге, бачок для отходов, шкафчик с лекарствами (рельсы-стеллаж),
  кафельная стена (текстура есть), в раковине вода с розоватым оттенком (тихо, без драмы).
- **Свет:** больничная трубка холодно-зелёная, мерцает чаще, чем в экипаже.
- **Звук:** тиканье электрокардиографа без пациента (одним из P2-предметов), гул ламп.
- **Настораживает:** кушетка застелена, но простыня вмята как после сна; пациента нет.

### 3.5 Грузовой отсек (18,6…23,6 м)

- **Назначение:** запчасти для ремонта (панель, кислород) и «испытательный» характер рейса.
- **Сюжет:** предметы для миссий ремонта: фильтр кислорода, кабель питания, предохранители.
- **P1:** стеллаж с ремонтным комплектом, ящики и контейнер под ремнями, грузовая сетка,
  ящик с инструментами, чёрные ящики испытательного оборудования (самописцы).
- **P2:** этикетки без текста (штрихкоды из картинок), ремни свисают, бочка, колёсная тележка,
  упаковочная плёнка, транспортировочные пломбы, ломик, пара лопнувших ящиков.
- **Свет:** одна жёлтая рабочая лампа в дальнем конце; весь остальной груз в тени.
- **Звук:** стук ремня о контейнер (ритм 2–3 с), капает конденсат, шелест плёнки.
- **Настораживает:** ряд крепёжных рельсов на полу заканчивается пустым местом — что-то увезли.

### 3.6 Реакторный отсек (23,9…28,6 м)

- **Назначение:** энергия и воздух — сердце сюжетной цепочки.
- **Сюжет:** восстановление питания (после ремонта панели) и кислородный узел.
- **P1:** щит автоматов (аварийное питание), кислородный узел (клапан, манометры, фильтр),
  реактор (блок, ядро), трубы с вентилями.
- **P2:** красная лента на ручке, обмотки кабелей, лужа масла, бирки «НЕ ВКЛ.», сумка с
  инструментом, нагар на панели, гул-вибрация на полу (визуально — рябь в кружке с водой).
- **Свет:** красный аварийный, мигает при замыкании; после ремонта меняется на тусклый белый.
- **Звук:** гул ядра, свист воздуха из неплотного клапана, стук насоса. После восстановления
  звук мягче — хорошо читаемый «успех» без музыки.
- **Настораживает:** все манометры стоят чуть выше нормы, но стрелки не дрожат.

### 3.7 Шлюз (корма, 28,9…33 м)

- **Назначение:** выход в космос, ремонт солнечной панели.
- **Сюжет:** EVA, возвращение, закрытие люка.
- **P1:** круглый люк со штурвалом, панель давления, шкафы со скафандрами (один пуст),
  скамья, шлем.
- **P2:** ботинки с магнитами, трос в бухте, жёлтые маркеры, лампа статуса, записка «ПРОВЕРИТЬ
  УПЛОТНЕНИЕ», брызги инея на нижней части люка, карабины на стене.
- **Свет:** тусклая белая лампа и зелёный индикатор люка (красный, когда открыто).
- **Звук:** тиканье металла, шипение утечки, при выходе — тишина (без звука в вакууме).
- **Настораживает:** в шкафу висит ровно один скафандр, остальные два — нет, хотя ячейки подписаны.

## 4. Свет по сюжету

| Состояние | Пилотская | Экипаж | Камбуз | Медотсек | Груз | Реактор | Шлюз |
|---|---|---|---|---|---|---|---|
| Авария (старт) | голубая панель | тьма | янтарь у капсулы | тьма | тьма | красный аварийный | зелёный индикатор |
| Питание есть | + панели | труба мигает | + лампа | труба | жёлтая лампа | красный → белый | белая лампа |
| После сна | как «питание», окно показывает новый вид | | | | | | |

## 5. Маршрут и темп

- Пролог (3–4 мин): камбуз в темноте → найти фонарь на магните → коридор до реактора.
- Каждый люк — короткая пауза: тишина, шорох, свет следующей комнаты.
- Между задачами игрок обязан вернуться через весь корабль; в пути каждый раз что-то
  изменилось (вторая кружка исчезла, кресло повернулось, лампа погасла) — без внезапных
  скримеров, максимум один «отключившийся свет».

## 6. Заказ моделей (Tripo3D)

Очередь **P1** (≈ 25 предметов): пилотское кресло, откидное кресло, штурвальная ручка,
навигационная консоль, ЭЛТ-монитор, радиоприёмник (ретро полевой), гарнитура, капсула сна,
кухонный блок, шкаф с едой, смотровая кушетка, шкаф с красным крестом, стойка капельницы,
стеллаж, ящик, контейнер, щит автоматов, кислородный узел с манометрами, реактор, вентиль,
скафандр, шлем, шкаф скафандров, люк со штурвалом, магнитные ботинки.

Очередь **P2** (≈ 30 предметов): кружки, термос, пакеты с едой, миска, ручной фонарь,
шприц, бинт, планшет, журнал, фото, рисунок, куртка, тапочки, ломик, плёнка, ремни, сумка,
инструменты, бачок, лампа хирурга, бирки и т. п. Часть можно сделать самим из простых форм.

Принцип: **сначала 3–4 пробных предмета** (кресло, радио, ЭЛТ, капсула) → оценка стиля →
массовая генерация. Все модели проходят: импорт в Godot, проверка масштаба/пропорций, наложение
текстур из ChatGPT (при необходимости перекраска), проверка коллизий и мерцания (скрипт-аудит).

## 7. Открытые вопросы к автору

1. Остаётся ли имя героя (Алексей «Эхо» Ветров) и корабль «Ариадна»?
2. Сколько «следов экипажа» оставляем (три заклеенные фамилии — это намёк; можно мягче)?
3. Нужен ли отдельный сюжетный объект в медотсеке (запись врача, лекарство для героя) или
   медотсек только атмосферный?
4. Окно: одна планета и дрейф или несколько «вех» по сюжету?
