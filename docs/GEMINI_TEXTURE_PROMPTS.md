# Полный промпт-пак: текстуры для ECHOES OF THE VOID

Генерация вручную в **Google AI Studio** (веб) с Pro-подпиской — бесплатно в рамках
дневных квот, Nano Banana доступен. Формат: PNG, 1:1 для тайлов/декалей/экранов,
2:1 для панорам/планет.

## Как генерить

1. AI Studio → Playground → модель с генерацией изображений (Nano Banana).
2. Вставь промпт. Если результат «не тот» — попроси «темнее/грязнее/без перспективы»
   или сгенерируй ещё варианты.
3. Скачай PNG, назови файл **точно именем из списка** (`metal_wall.png`).
4. Пришли сюда пачкой.
5. Никакого текста и водяных знаков на поверхности (кроме специально помеченных
   «с текстом» — там лучше пустой фон, надписи я нарисую сам).

## Общий стиль (добавляй в конец каждого промпта)

> PS1-era 1997 video game texture, pixelated, limited muted palette, grimy industrial
> derelict spaceship, flat orthographic view, no perspective, no baked lighting,
> no shadows, no text, no watermark.

Сначала попроси в начале: `seamless tileable` — для поверхностей.

## Что я сделаю с файлами

- тайлы: зеркальная укладка 2×2 → бесшовно, 256 px, палитра ~28 цветов;
- декали: чёрный фон → альфа, обрезка, 256 px;
- CRT: скан-линии, свечение, 256 px (текст надписей дорисую пиксельным шрифтом);
- панорамы: 2048×1024, планеты — фит под сферы, дыра — альфа;
- контактный лист для приёмки → подключение к материалам → рендеры «до/после».
