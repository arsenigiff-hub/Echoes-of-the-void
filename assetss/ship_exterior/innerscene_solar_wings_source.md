# Solar array source

- Asset: Satellite with solar wings
- Source: https://www.innerscene.com/tools/library/3d-parts/satellite-with-solar-wings-09ac21b8
- License: CC0, per the source page
- Download format: GLB
- Downloaded: 2026-11-13
- Runtime use: the source GLB is loaded directly; the game hides the satellite bus and keeps the original `Solar wings` and `Wing yokes and hinges` meshes. The mesh itself is not rebuilt.
- Runtime transform: uniform scale 0.35. The solar wing stays in its source orientation and is mounted to the outer hull side; only the original solar wing and hinge/yoke meshes are shown. Placement is in `scripts/story_progression.gd`.
