# Временный визуальный тест Fears to Fathom

Файлы в этой папке используются только сценарием
`.codex_qa/ship_clutter/capture_ftf_preview.gd`. Сцены и материалы основного
корабля от них не зависят.

- `bulkhead_enamel.png` — тестовая светлая окрашенная сталь.
- `deck_metal.png` — тестовое тёмное металлическое покрытие палубы.
- `shaders/vhs_ftf_preview.gdshader` — копия VHS-шейдера с фильтрацией linear и
  отдельным ползунком `retro_pixelation`; этим превью проверяется VHS при почти
  выключенной пиксельной квантизации.

Для кадра: Godot 4.7.2, GUI, разрешение 1280×800, запустить скрипт выше. После
просмотра теста решим, переносить ли выбранные настройки в основную игру.
