# Pixel texture set

Generated with built-in ImageGen; twenty distinct material textures. Approved direction: coarse pixels, scuffs and grime, minimal corrosion. Runtime mapping: scripts/ship_pixel_materials.gd. Godot import limits size to 256; nearest filtering with mipmaps.

## Shared prompt

Single seamless tileable square ALBEDO texture for a PS1/PS2 psychological space horror game. Hand-painted PIXEL ART on a coarse 128x128 pixel grid, nearest-neighbor enlarged, visible square pixel clusters, NO antialiasing, NO photographic fine detail. Heavily used but functional material, scuffed paint, scratches, grime, dust, restrained desaturated colors. NO orange rust or extensive corrosion. Flat orthographic evenly lit surface, no cast shadows or perspective, no text, no object outlines, no borders, no mirrored symmetry. Structured wear at plausible scale, not random blurry camouflage.
