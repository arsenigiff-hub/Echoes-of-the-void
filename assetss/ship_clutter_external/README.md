# Внешние ассеты для интерьера

## Мусорная корзина экипажа

- Автор исходника: Yughues (Nobiax).
- Источник и лицензия: [Free Trashes на OpenGameArt](https://opengameart.org/content/free-trashes), CC0 1.0.
- В архиве сохранены авторский `readme.txt` с текстом CC0, исходный пакет `Free_Trashes_original.7z`, выбранный `trash_01.obj` и его исходная текстура.
- В игре используется только низкополигональная форма `trash_01`: она уменьшена из сантиметров в метры, поставлена основанием на пол и получила материал `detail_dark_metal`. Исходная гладкая PBR-текстура заменена штатной пиксельной потёртой сталью проекта.
- Импорт воспроизводится из корня проекта: `D:\Steam\steamapps\common\Blender\blender.exe --background --python tools/import_ship_trash_bin.py`.
- Выбор ассета: форма простая, узнаваемая и низкополигональная; холодный металлический оттенок и яркий гладкий PBR-вид исходника в игру не перенесены.
